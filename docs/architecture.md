# Zachary Panel - 架构设计

## 1. 概述

Zachary Panel 是一个流量转发管理面板，由三部分组成：

- **Server（主控面板）**：部署在主控 VPS，提供 Web API 和 Agent 通信接口
- **Web 前端**：Vue 3 单页应用，通过浏览器访问
- **Agent（节点代理）**：部署在转发节点上，接收并执行转发任务

## 3. 通信协议

### 3.1 Server ↔ 前端
- HTTPS REST API
- JWT Bearer Token 认证
- Content-Type: application/json

### 3.2 Server ↔ Agent
- WSS (WebSocket Secure) 长连接
- Agent 主动连接 Server
- HMAC-SHA256 请求签名
- timestamp + nonce 防重放
- 任务通过 WebSocket 双向通信

### 3.3 Agent ↔ 转发目标
- 根据规则配置执行 nftables 规则或启动 gost 进程
- 不使用隧道通信，直接在节点本机操作

## 4. 数据流

### 4.1 节点注册流程
```
面板创建节点 → 生成install_token
              → 用户复制安装命令
              → Agent执行安装 → 携带install_token注册
              → Server验证 → 返回正式node_token
              → Agent保存配置 → 建立WSS长连接
```

### 4.2 转发规则创建流程
```
前端创建规则 → API请求到Server
             → Server入库 → 创建任务
             → 通过WSS下发给Agent
             → Agent执行(nft/gost)
             → Agent回传结果
             → Server更新规则状态
```

### 4.3 心跳流程
```
Agent定时(10s)发送心跳 → Server记录心跳时间
                       → Server检测超时Agent → 标记离线
```

### 4.4 延迟测试流程
```
前端发起测试 → Server创建测试任务
             → 通过WSS下发给Agent
             → Agent执行ping/tcping/dns
             → Agent回传测试结果
             → Server保存 → 前端展示
```

## 5. 安全边界

```
┌──────────────────────────────────────────────────────┐
│  Server (Trusted)                                     │
│  - 所有Agent请求必须签名验证                          │
│  - 不信任Agent上报的任何未校验数据                    │
│  - 任务类型白名单强制执行                             │
│  - 命令参数严格校验                                   │
│  - 审计日志完整记录                                   │
├──────────────────────────────────────────────────────┤
│  Agent (Untrusted - 可能被逆向)                       │
│  - 仅能执行白名单任务                                 │
│  - 不能执行任意命令                                   │
│  - 密钥可单独吊销                                     │
│  - 被破解后影响范围有限                               │
└──────────────────────────────────────────────────────┘
```

## 7. 技术选型理由

| 组件 | 选择 | 理由 |
|------|------|------|
| Web 框架 | Axum | 基于 Tower 生态，类型安全，WebSocket 支持好 |
| 数据库 | SQLite | 默认轻量，预留 PostgreSQL 接口 |
| ORM | SQLx | 编译时 SQL 检查，异步原生 |
| 前端 | Vue 3 + Naive UI | 简洁现代，TypeScript 支持好 |
| 构建 | Vite | 开发体验好，构建速度快 |
| WebSocket | tokio-tungstenite | 纯 Rust，配合 tokio 生态 |
| 签名 | HMAC-SHA256 | 标准算法，实现简洁 |
| 转发 | nftables + gost | 覆盖内核转发和应用层转发 |
